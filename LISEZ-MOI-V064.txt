ARCHITECTURE IMPLEMENTEE EN VRAI CODE NATIF
- Paramètres compact : une commande « Modifier les catégories » remplace la liste interminable.
- Images : un bouton visible « Modifier les catégories d'images » mène au gestionnaire.
- Vidéos : un bouton visible « Modifier les catégories vidéo » mène au même gestionnaire avec filtre vidéo.
- Le gestionnaire a deux onglets Images / Vidéos et affiche des cartes avec images réellement choisies par l'utilisateur, noms et nombres provenant des médias accessibles sur l'appareil.
- Une seule catégorie partagée (mêmes préférences) : pas de copie homonyme entre onglets. Les nouvelles catégories créées dans un onglet sont propres à ce type ; les catégories communes existantes sont conservées.
- Le bouton Retour du gestionnaire revient à l'origine (Paramètres / Images / Vidéos). L'éditeur revient au gestionnaire et la sauvegarde idem. Aucun deuxième bouton Retour décoratif.
- Editeur : photo choisie via ACTION_OPEN_DOCUMENT, permission URI persistante, icône, nom, aperçu et déplacement dans la liste. Les noms renommés sont résolus aussi pour les anciens liens des catalogues illustrés.
- Suppression de catégorie : conservation des fichiers présélectionnée. Si Android 11+ et permission média complète, l'option corbeille requiert deux confirmations dans l'app + validation Android ; maximum 500. Si refus Android, catégorie conservée.
- Classement manuel : maximum 1000 par opération, écritures confirmées par lots et compteurs réels réussites / déjà classés / erreurs ; aucune suppression ou déplacement du fichier original.
- Import des albums : « Depuis la galerie » laisse choisir, « Tous les albums » présélectionne les albums, destinations choisies explicitement, limite 1000, succès uniquement si sauvegarde confirmée. Pas de copies physiques.
- Photos/Vidéos dans « À classer » filtrent sur place, « Autres vidéos » montre les vidéos sans catégorie, recherche nom / album / catégorie / type (captures d'écran comprises).
- Galerie : lots de 120 conservés, choix Petites/Moyennes/Grandes, cartes verticales et titres sur deux lignes.
- Suppression médias : maximum 500, sélection cochée + confirmation finale + Android quand disponible. Réinitialisation : deux confirmations.
- Tri automatique, suggestions IA, sons et thèmes alternatifs non implémentés : ils restent explicitement désactivés, et aucune copie ou analyse IA fictive n'est simulée.

VISUELS ET LIMITES HONNETES
Les écrans sont de vrais composants Android actifs, utilisant les ressources graphiques du projet et non des captures d'écran inertes. La mise en page suit l'orientation des maquettes ; elle n'est pas une reproduction pixel par pixel sur toutes les tailles de téléphone. Les anciennes planches de catégorie de la galerie Images/Vidéos sont des images fixes : après renommage, leurs inscriptions dessinées peuvent rester anciennes, mais la nouvelle page Mes catégories affiche le vrai nom et les zones tactiles historiques sont redirigées par alias.
Les nombres affichés dans les nouvelles listes de catégories et le rapport de classement viennent des données réelles accessibles, pas des valeurs fictives des maquettes. Les fichiers originaux ne sont pas modifiés par le classement logique.
