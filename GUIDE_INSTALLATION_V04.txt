LES LAPIBREIZH — V0.4 — GUIDE DE TRANSITION SÛRE

CE FICHIER ZIP CONTIENT LE CODE SOURCE, PAS UN APK ET PAS LA CLÉ PRIVÉE.
La compilation sur GitHub Actions est à lancer APRÈS avoir configuré les deux secrets de signature.

PRÉREQUIS : conserve ta V0.3 installée. Sauvegarde actuellement le classement par
Paramètres > Exporter la sauvegarde JSON ; garde le JSON dans Téléchargements.
Ne désinstalle pas V0.3 avant que l'APK V0.4 signé ait été compilé avec succès !

UNE SEULE TRANSITION NON COMPATIBLE :
La V0.3 a été signée avec une clé DEBUG éphémère de GitHub Actions.
Sa clé n'est pas disponible ici : la nouvelle V0.4 signée avec une clé privée NE POURRA
PAS se mettre à jour par-dessus cette V0.3. Il faudra une seule fois désinstaller V0.3,
installer le nouveau fichier app-release.apk et réimporter le JSON.
Désinstaller l'application efface normalement ses données internes ; les photos
originelles restent inchangées, mais le classement peut perdre des associations si
les identifiants MediaStore ont changé. Vérifier le classement après l'import.

À PARTIR DE V0.4 :
Utiliser toujours LA MÊME CLÉ pour toutes les versions ultérieures. Elle est fournie
SÉPARÉMENT dans Lapibreizh-Kit-Signature-PRIVE-V04.zip. Ne jamais mettre ce kit,
le .jks, son mot de passe ou le texte de secrets dans Gitling ni dans un dépôt public.
Garder plusieurs copies personnelles sécurisées de ce kit hors de GitHub.

CONFIGURATION GITHUB, UNE SEULE FOIS :
1. Télécharge le kit PRIVÉ séparé et extrais Lapibreizh-SECRETS-PRIVES-V04.txt.
2. GitHub > dépôt Les-Lapibreizh-Android > Settings > Secrets and variables > Actions.
3. Clique New repository secret. Crée LAPIBREIZH_KEYSTORE_B64 avec toute la longue
   valeur indiquée dans ton fichier PRIVÉ, sans retour à la ligne ni espace ajouté.
4. Recommence avec LAPIBREIZH_KEYSTORE_PASSWORD et la valeur indiquée dans ce fichier.
5. Ensuite seulement, extrais ce ZIP de sources V0.4 à la racine du dépôt Gitling
   et remplace les fichiers identiques. Stage all > Commit > Push.
6. GitHub Actions doit afficher une compilation VERTE. Télécharge l'artefact
   Les-Lapibreizh-V04-APK-signe, extrais son app-release.apk.
7. Exporte de nouveau ton classement V0.3 si tu y as fait des modifications ;
   ensuite seulement désinstalle V0.3, installe V0.4 et réimporte ton JSON.
8. Teste les catégories et les fichiers avec 1 ou 2 médias sans importance.

SI ACTIONS EST ROUGE : ne désinstalle PAS la V0.3. Vérifier le nom exact et la valeur
des deux secrets ; aucun APK non signé ne doit être installé.

Cette V0.4 n'est pas validée sur appareil avant ton essai. La signature de la V0.4
est conçue pour devenir stable : elle ne rend pas la V0.3 compatible rétroactivement.
